# Rime Config · Rime 配置

Personal macOS Chinese input method setup — Squirrel (鼠鬚管) + rime-ice (雾凇拼音).

个人用的 macOS 中文输入法配置。

```bash
curl -fsSL https://raw.githubusercontent.com/ziangchen7/rime-config/main/install.sh | bash
```

One command installs everything. The same command updates everything.
Requires macOS, [Homebrew](https://brew.sh) and git.

一条命令装完，同一条命令也用于更新。

---

## English

### What you get

- Linear candidate bar, frosted glass, follows system light/dark
- Radical lookup (`uu` + component pinyin) with candidates re-ranked by
  character frequency, so common characters come first
- Font fallback chain, so rare CJK Ext-B/C/D characters don't render as tofu
- Pinyin readings shown next to radical-lookup candidates
- One-key toggles for traditional/simplified, punctuation and emoji

### Install

Run the command above. After a first install, add Squirrel in
**System Settings → Keyboard → Input Sources**.

The script installs or upgrades the Squirrel cask and Plangothic font, clones or
pulls plum, installs or updates rime-ice plus the tone-marked reading
dictionaries, syncs this repo's config, regenerates the frequency table from the
current dictionaries, and triggers a redeploy.

It is idempotent and safe to re-run. Local uncommitted changes are stashed, not
discarded. Pre-existing config files are backed up on first deploy.

### Key bindings

| Key | Action |
|---|---|
| `Ctrl+Shift+F` | Simplified ⇄ Traditional |
| `Ctrl+Shift+P` | Chinese ⇄ English punctuation |
| `Ctrl+Shift+E` | Toggle emoji |
| `F4` | Schema menu |
| `Ctrl+Delete` | Delete / demote the selected candidate |
| `` ` `` | Auxiliary-code filter — `hui` `` ` `` `cao` → 荟 |
| `uu` + pinyin | Radical lookup — `uuririri` → 晶 |

Auxiliary code is for when you know the reading but there are too many
homophones. Radical lookup is for when you only know the shape.

### Files

| File | Purpose |
|---|---|
| `squirrel.custom.yaml` | Appearance — colors, fonts, layout |
| `default.custom.yaml` | Global key bindings |
| `rime_ice.custom.yaml` | Schema behavior — radical lookup, annotation, filters |
| `lua/radical_sort_filter.lua` | Re-ranks radical-lookup candidates |
| `install.sh` | Install / update |

Only custom files are tracked. Dictionaries (44 MB) and build artifacts (74 MB)
come from plum.

`lua/char_freq.lua` is generated by `install.sh` and deliberately untracked — it
is derived from the dictionaries, so it must be regenerated when they update.
The filter degrades to tier-only sorting if it is missing.

`*.userdb/` is not tracked either. It is LevelDB bound to an `installation_id`,
so copying the directory across machines may not work. Use **Sync User Data**
from the menu bar instead: it exports plain text to `~/Library/Rime/sync/`, which
is portable. Copy that directory to the new machine and sync again to merge.

### Note

Any config change needs **Deploy** from the menu bar icon to take effect.

## 中文

### 有什么

- 横排候选栏，毛玻璃背景，亮暗配色跟随系统
- 拆字（`uu` + 部件拼音）候选按词频重排，常用字排前面
- 字体回退链，生僻字不再显示成方框
- 拆字候选旁边显示拼音读音
- 简繁、中英标点、Emoji 一键切换

### 安装

跑上面那条命令。首次安装后还需在 **系统设置 → 键盘 → 输入方式** 添加「鼠鬚管」。

脚本会装或升级鼠鬚管和 Plangothic 字体、克隆或拉取 plum、装或更新雾凇拼音和
带声调注音词典、同步本仓库配置、按当前词库重算词频表，最后触发重新部署。

幂等，重复跑安全。本地未提交的改动会 `git stash` 存起来而不是丢掉，
首次部署遇到已有配置文件会先备份。

### 快捷键

| 键 | 作用 |
|---|---|
| `Ctrl+Shift+F` | 简繁切换 |
| `Ctrl+Shift+P` | 中英标点 |
| `Ctrl+Shift+E` | Emoji 开关 |
| `F4` | 方案选单 |
| `Ctrl+Delete` | 删除／降权选中的候选词 |
| `` ` `` | 辅码筛选，`hui` `` ` `` `cao` → 荟 |
| `uu` + 拼音 | 拆字，`uuririri` → 晶 |

辅码用于知道读音但同音字太多；拆字用于不知道读音、只看得出字形。

### 文件

| 文件 | 作用 |
|---|---|
| `squirrel.custom.yaml` | 外观：配色、字体、排版 |
| `default.custom.yaml` | 通用快捷键 |
| `rime_ice.custom.yaml` | 方案行为：拆字、注音、滤镜 |
| `lua/radical_sort_filter.lua` | 拆字候选重排 |
| `install.sh` | 安装／更新 |

只跟踪自定义文件。词库（44 MB）和编译产物（74 MB）由 plum 提供。

`lua/char_freq.lua` 由 `install.sh` 生成，故意不入库 —— 它是从词库派生的，
词库更新后就该重算。缺失时滤镜会降级为只按码点分档，不报错。

`*.userdb/` 也没跟踪。它是 LevelDB 且绑定 `installation_id`，跨机器直接拷可能
不识别。用菜单栏的「同步用户资料」代替：它会导出纯文本到 `~/Library/Rime/sync/`，
这个格式跨机器通用。把该目录拷到新机器再点一次同步即可合并。

### 注意

改完任何配置都要点菜单栏图标「重新部署」才生效。
